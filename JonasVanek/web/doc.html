1. ONBOARDING PRO NOVÉHO VÝVOJÁŘE

Tento dokument slouží pro rychlé zapracování nového člena týmu do projektu Flappy Palach. Předpokládá se základní znalost Python, PHP a MySQL.

Začínáme

Požadavky

  • Python 3.10 nebo novější
  • XAMPP (Apache + MySQL)
  • Textový editor (VS Code, PyCharm, Sublime Text)
  • Git (pro verzování kódu)

Instalace projektu

KROK 1: Stažení projektu

Zkopíruj celou složku projektu do svého pracovního adresáře. Struktura by měla vypadat:

flappy_palach/
├── flappy_palach_commented.py
├── img/
│   ├── bird1.png
│   ├── bird2.png
│   ├── palachvez.png
│   └── pozadi.png
├── config.php
├── login.php
├── register.php
├── submit_score.php
├── get_scores.php
├── get_user_scores.php
├── change_username.php
├── database.sql
├── index.html
├── style.css
└── script.js
KROK 2: Nastavení databáze
  1. Spusť XAMPP Control Panel
  2. Klikni Start u Apache a MySQL
  3. Otevři prohlížeč a jdi na http://localhost/phpmyadmin
  4. Vytvoř novou databázi s názvem flappy_palach
  5. Otevři soubor database.sql a zkopíruj jeho obsah
  6. V phpMyAdmin klikni na záložku SQL a vlož zkopírovaný kód
  7. Klikni Provést
KROK 3: Umístění webových souborů

Zkopíruj všechny PHP, HTML, CSS a JS soubory do:

  • Windows: C:\xampp\htdocs\flappy_palach\
  • Mac: /Applications/XAMPP/htdocs/flappy_palach/
KROK 4: Instalace Python závislostí 
pip install pygame
KROK 5: Test instalace
  1. Otevři prohlížeč na http://localhost/flappy_palach/
  2. Měla by se zobrazit hlavní stránka s přihlašovacím dialogem
  3. Spusť Python hru: python flappy_palach_commented.py

Architektura projektu

Základní komponenty

Python hra (flappy_palach_commented.py): Klientská desktopová aplikace. Komunikuje s PHP backendem přes HTTP požadavky.

PHP backend (6 souborů): REST API které zpracovává login, registraci a ukládání skóre. Každý endpoint vrací JSON odpověď.

MySQL databáze: Dvě tabulky (users, scores) propojené foreign key.

Web frontend (HTML/CSS/JS): Žebříček s přihlášením, filtry a osobním profilem.

Datový tok

1. Uživatel spustí Python hru
2. Zadá přihlašovací údaje
3. Python pošle POST na login.php
4. PHP ověří heslo v databázi (password_verify)
5. PHP vrátí JSON s user_id
6. Uživatel hraje
7. Po smrti ptáčka se odešle skóre na submit_score.php
8. PHP zkontroluje best-score logiku
9. PHP smaže starý záznam (pokud nový je lepší)
10. PHP vloží nový záznam
11. Web žebříček načte data z get_scores.php

Kde najdu co

Herní logika

  • Kolizní detekce: funkce check_collision() na řádku ~857
  • Fyzika ptáčka: funkce main_game() na řádku ~943
  • Obtížnosti: slovník DIFFICULTY_PROFILES na řádku ~159
  • Login obrazovka: funkce login_register_screen() na řádku ~434

Backend API

  • Autentizace: login.php (řádky 40-65 - ověření hesla)
  • Best-score: submit_score.php (řádky 50-80 - DELETE+INSERT logika)
  • Validace jména: change_username.php (řádky 35-45 - regex check)

Frontend

  • Auth modal: script.js funkce wireAuthModal()
  • Profil panel: script.js funkce openProfilePanel()
  • Filtry: script.js funkce filterAndDisplay()

    "lehka": {
        "speed_inc": 0.0,

}

Testování změn

Po jakékoliv úpravě kódu proveď tyto kroky:

  1. Python změny: Zavři hru a spusť znovu
  2. PHP změny: Pouze obnov stránku v prohlížeči (PHP neukládá stav)
  3. JS/CSS změny: Obnov stránku s vymazáním cache (Ctrl+Shift+R)
  4. Databázové změny: Spusť SQL příkaz v phpMyAdmin

Časté problémy a řešení

Problém: Python hra hlásí "Chyba připojení"

Řešení: Zkontroluj že Apache v XAMPP běží. Otevři http://localhost/flappy_palach/login.php v prohlížeči - měl by vrátit JSON chybu.

Problém: "Access denied for user root"

Řešení: V phpMyAdmin zkontroluj uživatele. Možná máš nastavené heslo pro root. Uprav config.php.

Problém: Skóre se neuloží

Řešení: Zkontroluj Console výstup Pythonu. Měla by tam být zpráva "Skóre úspěšně odesláno" nebo chyba.

2. UŽIVATELSKÁ PŘÍRUČKA

Návod pro hráče jak používat systém Flappy Palach.

Začínáme

Registrace nového účtu

  1. Spusť hru flappy_palach_commented.py
  2. Otevře se okno s přihlášením
  3. Klikni na záložku "REGISTER"
  4. Zadej přihlašovací jméno (minimálně 3 znaky)
  5. Zadej heslo (minimálně 4 znaky)
  6. Klikni "START" nebo stiskni Enter
Poznámka: Jméno musí být unikátní. Pokud už existuje, zobrazí se chyba "Jméno je již obsazené".

Přihlášení

  1. Spusť hru
  2. Zadej své jméno a heslo
  3. Klikni "START"

Hraní

Výběr obtížnosti

Po přihlášení si vybereš jednu ze tří úrovní:

  • Lehká: Konstantní rychlost, mezera se nezmenšuje
  • Střední: Rychlost roste o 0.25 každých 3 bodů, mezera se zmenšuje o 3px
  • Těžká: Rychlost roste o 0.5 každých 3 bodů, mezera se zmenšuje o 6px

Ovládání ve hře

  • Mezerník nebo klik myší - skok ptáčka
  • ESC - pauza (zobrazí menu)

Cíl hry

Prolétnout co nejvíce trubkami bez nárazu. Za každou proletnutou trubku získáš 1 bod.

Systém skóre

Jak funguje žebříček

Systém ukládá pouze tvoje nejlepší skóre na každé obtížnosti. Pokud dosáhneš lepšího výsledku, starý záznam se automaticky přepíše.

Příklad:

1. Hraješ na Střední obtížnosti → dosáhneš 50 bodů → uloží se
2. Hraješ znovu na Střední → dosáhneš 30 bodů → NEULOŽÍ SE (je horší než 50)
3. Hraješ znovu na Střední → dosáhneš 80 bodů → ULOŽÍ SE (starý záznam 50 se smaže)

Webový žebříček

Přístup k žebříčku

  1. Otevři prohlížeč
  2. Jdi na http://localhost/flappy_palach/
  3. Přihlaš se stejnými údaji jako ve hře

Funkce žebříčku

  • Vyhledávání: Zadej jméno hráče do pole nahoře
  • Filtry: Klikni na tlačítka Lehká/Střední/Těžká pro zobrazení jen té obtížnosti
  • Profil: Po přihlášení klikni na tlačítko "PROFIL" pro zobrazení tvých statistik

Osobní profil

V profilu najdeš:

  • Nejlepší skóre: Tvůj rekord na každé obtížnosti
  • Historie pokusů: Všechny tvoje hry seřazené od nejnovější
  • Změna jména: Možnost změnit přihlašovací jméno

Změna jména

  1. V profilu najdi sekci "Změnit jméno"
  2. Zadej nové jméno
  3. Klikni "OK"
Upozornění: Nové jméno nesmí být již používané jiným hráčem.

Časté dotazy

Q: Zapomněl jsem heslo. Jak ho obnovím?
A: Systém momentálně nemá funkci obnovy hesla. Kontaktuj správce pro reset.

Q: Můžu mít více účtů?
A: Ano, ale každý účet musí mít unikátní jméno.

Q: Proč se moje horší skóre neuložilo?
A: Systém ukládá pouze tvůj nejlepší výsledek na každé obtížnosti.

Q: Můžu smazat svůj účet?
A: Smazání účtu momentálně není možné přes rozhraní. Kontaktuj správce.

Q: Jak se dostanu do top 3?
A: Musíš dosáhnout jednoho ze tří nejlepších skóre na dané obtížnosti.

3. OBSAH PREZENTACE PRO INVESTORA

Doporučená struktura prezentace projektu Flappy Palach pro potenciální investory nebo zadavatele.

Slide 1: Titulní snímek

  • Název projektu: Flappy Palach
  • Podtitul: Full-stack hra s online žebříčkem
  • Tvoje jméno a datum
  • Vizuál: Screenshot hlavní obrazovky hry

Slide 2: Problém a řešení

Problém:

  • Tradiční jednoduché hry nemají online komponentu
  • Chybí motivace k opakovanému hraní (žádný žebříček)
  • Offline hry neumožňují soutěživost mezi hráči

Řešení:

  • Kombinace desktopové hry s webovým žebříčkem
  • Uživatelské účty a osobní statistiky
  • Tři úrovně obtížnosti pro různé typy hráčů

Slide 3: Technologický stack

Frontend: HTML5, CSS3, JavaScript ES6+
Backend: PHP 8, MySQL 8, Apache
Desktopová hra: Python 3.10+, Pygame
Komunikace: RESTful API, JSON

Zdůrazni:

  • Moderní, osvědčené technologie
  • Škálovatelná architektura
  • Bezpečnost (bcrypt, prepared statements)

Slide 4: Klíčové funkce

Vyber 4-5 nejdůležitějších funkcí:

  1. Uživatelské účty - registrace, login, změna jména
  2. Best-score systém - ukládání pouze nejlepších výsledků
  3. Tři obtížnosti - Lehká, Střední, Těžká
  4. Webový žebříček - vyhledávání, filtry, statistiky
  5. Osobní profil - historie všech pokusů

Slide 5: Architektura systému

Ukázka komunikačního toku:

Python hra ──► PHP API ──► MySQL databáze
     ▲                           │
     └───────────────────────────┘
            JSON odpověď

Zdůrazni:

  • Oddělení prezentační vrstvy od logiky
  • REST API umožňuje snadné rozšíření (mobilní app)
  • Relační databáze zajišťuje integritu dat

Slide 6: Databázový model

  • Ukázka ER diagramu (soubor er.png)
  • Vysvětlení vztahu 1:N mezi users a scores
  • Zmínka o foreign key CASCADE DELETE

Slide 7: Bezpečnost

Implementovaná bezpečnostní opatření:

  • Password hashing: Bcrypt s cost 10
  • SQL injection prevence: Prepared statements
  • XSS protection: Escapování HTML na frontendu
  • Input validace: Server i klient
  • Foreign key constraints: Referenční integrita

Slide 8: Živá ukázka

Doporučený postup pro demo:

  1. Otevři webový žebříček - ukaž top 3 hráče
  2. Spusť Python hru
  3. Zaregistruj nový účet
  4. Vyber obtížnost a zahraj krátkou hru
  5. Po smrti ukaž že se skóre objevilo v žebříčku
  6. Otevři profil - ukaž statistiky a historii
Tip: Připrav si předem účet s dobrým skóre, aby demo vypadalo působivě.

Slide 9: Automatizované testy

Zmínka o quality assurance:

  • Test 1: Kolizní detekce (Python unittest)
  • Test 2: Databázové operace (PHP)
  • Možnost živého spuštění testů

Slide 10: Výzvy a řešení

Technické výzvy během vývoje:

Výzva 1: Best-score logika
Řešení: DELETE + INSERT pattern místo UPDATE

Výzva 2: Synchronizace jména mezi tabulkami
Řešení: Denormalizace username sloupce pro rychlost

Výzva 3: Ochrana proti duplicitním záznamům
Řešení: UNIQUE constraint + aplikační logika
