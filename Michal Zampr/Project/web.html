Tetris Game

About the Game

Tetris is a classic puzzle game where the player must arrange falling blocks called Tetrominoes to form complete horizontal lines. When a line is completed, it disappears, and the blocks above move down. The game ends when the blocks stack up to the top of the screen.

Gameplay

  • Blocks fall automatically from the top of the grid.
  • Player can move the blocks left, right, or down using arrow keys.
  • Rotate the blocks using the up arrow key.
  • Complete horizontal lines to earn points and clear space.
  • The game gets faster as you progress.
  • The game ends when new blocks cannot spawn at the top of the grid.

Controls

  • Left Arrow: Move block left
  • Right Arrow: Move block right
  • Down Arrow: Move block down faster
  • Up Arrow: Rotate block
  • Escape (ESC): Return to Menu

Features

  • Classic Tetris gameplay with random colored Tetrominoes
  • Instant line clear
  • Menu with Play and Quit buttons
  • Safe game over handling
