Flappy Bird

Kompletní průvodce pro nové hráče — od instalace po první místo v žebříčku.

🚀 Začínáme

Projekt se skládá ze dvou částí: desktopové hry (spouštíš lokálně) a webové stránky (server musí běžet).

Instalace závislostí

Ujisti se, že máš Python 3.11+ a nainstaluj pygame a flask příkazem v terminálu.

Spuštění serveru

V adresáři projektu spusť python server.py. Server poběží na localhost:5000.

Registrace účtu

Otevři localhost:5000 v prohlížeči, přejdi na záložku Účet a vytvoř si uživatelské jméno. Bez toho nemůžeš ukládat skóre!

Spuštění hry

Spusť python hra.py. Zobrazí se herní okno 480×700 px.

🏆 Ukládání skóre

Po skončení hry (kolize nebo pád) se zobrazí formulář. Zadej své registrované uživatelské jméno a potvrď Enterem.

💡 Systém ukládá pouze tvůj osobní rekord. Pokud zahraješ hůř než minule, skóre se nepřepíše.

Žebříček zobrazuje top 10 hráčů seřazených podle nejvyššího skóre. Výsledky si můžeš prohlédnout i na webové stránce localhost:5000.

❓ Časté problémy

„Uživatel není na webu" — co to znamená?

Hra ověřuje, zda jméno, které zadáváš po konci hry, existuje v registrační databázi. Musíš se nejdříve zaregistrovat přes web (localhost:5000 → Účet).

Server se nespustí

Zkontroluj, zda máš nainstalovaný Flask (pip install flask) a zda port 5000 není blokovaný jiným programem.

01

O projektu

Flappy Bird je plně funkční desktopová hra vytvořená v Pythonu jako maturitní práce. Kombinuje herní mechaniku inspirovanou klasikou s moderním webovým backendem pro sdílení výsledků.

02

Problém, který řešíme

Jednoduché hry chybí modernímu globálnímu žebříčku a komunitnímu rozměru. Flappy Bird tento problém řeší kombinací offline hry s online backendem.

Klíčová inovace: Hráč musí být registrován přes web, aby mohl ukládat skóre. Tím vzniká ověřená komunita hráčů bez anonymního spamování žebříčku.

03

Technologický stack

  • Python 3.11 + Pygame — produkčně připravená herní smyčka běžící na 60 FPS
  • Flask REST API — odlehčený server, snadno škálovatelný na cloud (Heroku, Railway)
  • JSON databáze — vhodné pro prototyp; připraveno pro migraci na PostgreSQL
  • Webové rozhraní v čistém HTML/CSS/JS — bez závislostí, rychlé načítání
  • Plně modulární kód — každá komponenta může být vyměněna nezávisle
04

Obchodní potenciál

Projekt je připraven jako základ pro monetizaci:

  • Prémiové skiny a kosmetika pro ptáka (mikrotransakce)
  • Turnaje s prémiovým vstupem a prize poolem
  • School edition — herní platforma pro výuku programování
  • White-label verze pro firemní teambuildingy
05

Roadmapa rozvoje

  • Fáze 1 — Migrace databáze na SQLite / PostgreSQL, hashování hesel (bcrypt)
  • Fáze 2 — Globální online žebříček s real-time aktualizacemi (WebSocket)
  • Fáze 3 — Mobilní port (Kivy / React Native), více herních módů
  • Fáze 4 — Sociální funkce: přátelé, výzvy, achievementy

Hledáme: Seed investici nebo mentora pro přechod od MVP k produkční platformě. Stávající kódová základna je čistá, komentovaná a rozšiřitelná.

06

Tým & Kontakt

Projekt vytvořen jako individuální maturitní práce — důkaz schopnosti dodat kompletní produkt od návrhu po nasazení.

  • Herní vývoj: fyzika, kolize, animace, stavový automat
  • Backend: REST API design, autentizace, persistence dat
  • Frontend: responzivní UI, UX design, animace
  • Devops: lokální deployment, dokumentace, onboarding

📁 Co dělá který soubor

🐍 hra.py

  • Hlavní herní smyčka (Pygame)
  • Fyzika ptáka + kolize
  • Vykreslování grafiky
  • Stavový automat (MENU → HRA → …)
  • Lokální čtení/zápis JSON souborů

🌶️ server.py

  • Flask webový server
  • API endpointy (register, login, scores)
  • Čtení/zápis prihlaseni.json
  • Servírování index.html

🌐 index.html

  • Webové UI pro hráče
  • Žebříček (live z API)
  • Registrace a přihlášení
  • Info o hře a obtížnostech

📄 JSON soubory

  • highscores.json — top 10 skóre
  • prihlaseni.json — uživatelé + hesla
  • ⚠️ Hesla jsou plaintext — plánuje se bcrypt

🔧 Kde začít s úpravami

Chceš přidat novou funkci? Zde jsou nejčastější vstupní body:

Nová obtížnost

V hra.py, slovník OBTIZNOSTI (řádek ~10) — stačí přidat nový klíč s hodnotami gravity, flap, pipe_speed, pipe_gap.

Nový API endpoint

V server.py přidej novou funkci s dekorátorem @app.route('/api/...'). Vzor je stejný jako stávající endpointy.

Úprava grafiky ptáka

Funkce kresli_ptaka() v hra.py — vše je kresleno Pygamem (rect, circle, polygon), žádné obrázky.

Úprava webu

Vše je v jednom souboru index.html — CSS, HTML i JS. Pro větší projekt doporučujeme rozdělit do samostatných souborů.

🚨 Známé technické dluhy

  • 🔴 Hesla nejsou hashována — prihlaseni.json obsahuje plaintext hesla
  • 🟡 Žádný JWT / session — autentizace je jen jednosměrná při ukládání skóre
  • 🟡 JSON jako DB — race conditions při souběžném zápisu
  • 🟢 Grafika bez sprite sheets — vše je procedurální, snadno upravitelné
