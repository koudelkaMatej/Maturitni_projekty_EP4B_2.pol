Manuály projektu

Uživatelský manuál, prezentace pro investora a onboarding pro nového spolupracovníka.

🚀 Jak začít

Instalace závislostí

Ujisti se, že máš Python 3.11+. Spusť: pip install pygame flask

Spuštění serveru

V adresáři projektu spusť python server.py. Server poběží na localhost:5000.

Registrace účtu

Otevři localhost:5000, přejdi na záložku Účet a vytvoř uživatelské jméno. Bez toho nelze ukládat skóre.

Spuštění hry

Spusť python hra.py. Zobrazí se herní okno 480 × 700 px.

🏆 Ukládání skóre

Po kolizi nebo pádu se zobrazí formulář. Zadej své registrované uživatelské jméno a potvrď Enterem.

💡 Systém ukládá pouze tvůj osobní rekord. Horší výsledek existující skóre nepřepíše.

Žebříček top 10 hráčů je dostupný v menu hry i na webu localhost:5000.

❓ Časté problémy

„Uživatel není na webu"

Jméno musí existovat v registrační databázi. Registruj se přes localhost:5000 → Účet.

Server se nespustí

Zkontroluj instalaci Flasku: pip install flask. Port 5000 nesmí být obsazený.

Pygame okno se neotevře

Zkontroluj instalaci: pip install pygame. Na Linuxu možná chybí libsdl2.

01

O projektu

Flappy Bird je plně funkční desktopová hra v Pythonu s moderním webovým backendem pro sdílení výsledků. Vytvořeno jako maturitní práce — kompletní produkt od návrhu po nasazení.

02

Problém, který řešíme

Jednoduché hry postrádají globální žebříček a komunitní rozměr. Flappy Bird propojuje offline hru s online backendem.

Klíčová inovace: Ověřená komunita hráčů — skóre může uložit jen registrovaný uživatel. Žádný anonymní spam žebříčku.

03

Technologický stack

  • Python 3.11 + Pygame — produkční herní smyčka na 60 FPS
  • Flask REST API — odlehčený server, připraven na cloud (Railway, Render)
  • JSON databáze — rychlý prototyp, připraveno na migraci do PostgreSQL
  • Čisté HTML/CSS/JS — bez závislostí, rychlé načítání
  • Modulární architektura — každá část lze vyměnit nezávisle
04

Obchodní potenciál

  • Prémiové skiny a kosmetika — mikrotransakce bez pay-to-win
  • Turnaje s prémiovým vstupem a prize poolem
  • School edition — platforma pro výuku programování
  • White-label verze pro firemní teambuildingy
05

Roadmapa rozvoje

  • Fáze 1 — SQLite / PostgreSQL, hashování hesel (bcrypt)
  • Fáze 2 — Globální žebříček s real-time aktualizacemi (WebSocket)
  • Fáze 3 — Mobilní port (Kivy), více herních módů
  • Fáze 4 — Sociální funkce: přátelé, výzvy, achievementy

Hledáme: Mentora nebo seed investici pro přechod od MVP k produkční platformě. Kódová základna je čistá a rozšiřitelná.

06

Tým & Dovednosti

  • Herní vývoj — fyzika, kolize, animace, stavový automat
  • Backend — REST API design, autentizace, persistence dat
  • Frontend — responzivní UI, UX design, multi-page web
  • Dokumentace — technická, uživatelská, investorská prezentace

🔧 Kde začít s úpravami

Nová obtížnost

V hra.py — slovník OBTIZNOSTI (řádek ~10). Přidej klíč s hodnotami gravity, flap, pipe_speed, pipe_gap.

Nový API endpoint

V server.py — přidej funkci s dekorátorem @app.route(). Nezapomeň přidat routu do Flask i odkaz v HTML.

Úprava grafiky ptáka

Funkce kresli_ptaka() v hra.py — vše je procedurální (rect, circle, polygon), žádné PNG soubory.

🚨 Technické dluhy

  • 🔴
    Hesla nejsou hashována — prihlaseni.json obsahuje plaintext. Cíl: přejít na bcrypt.
  • 🟡
    Žádný JWT / session — autentizace je jen jednosměrná při ukládání skóre.
  • 🟡
    JSON jako DB — možné race conditions při souběžném zápisu více hráčů.
  • 🟢
    Procedurální grafika — vše kresleno Pygamem, snadno upravitelné bez externích assetů.
