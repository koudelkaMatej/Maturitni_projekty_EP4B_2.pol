Hloubková analýza implementace

01 / Backend & Autentizace

Registrace a přihlašování využívá Flask Sessions pro bezpečné udržení stavu uživatele. SQL dotazy jsou parametrizovány pro ochranu proti SQL Injection.

02 / Randomizační Algoritmus

Využívám 7-Bag systém, který simuluje losování ze sáčku. Zaručuje, že hráč dostane každou ze sedmi kostek právě jednou v rámci jedné sady.

03 / Geometrické Kolize

Funkce valid() provádí analýzu herního pole. Kontroluje matici mřížky dříve, než dovolí překreslení objektu na novou souřadnici.

04 / Bodová Progrese

Bodování je nelineární a dynamicky se škáluje s levelem. Systém odměňuje riskování pomocí vysokých multiplikátorů za více řad najednou.

05 / Dynamická Gradace

Obtížnost je řízena algoritmem, který s každým levelem zkracuje interval pádu kostky, čímž progresivně zvyšuje nároky na reakční dobu hráče.

06 / UI Design & Layout

Karty využívají moderní CSS Grid pro responzivitu. Styl "Glassmorphism" tvoří poloprůhledné pozadí s neonovým ohraničením (border-top) pro vizuální oddělení témat.
