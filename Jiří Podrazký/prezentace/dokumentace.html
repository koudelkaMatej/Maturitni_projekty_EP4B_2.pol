Technická specifikace

Tento dokument poskytuje detailní popis architektury, datových modelů a síťových protokolů použitých v projektu Space Invaders Enterprise.

1. Systémová architektura

Projekt využívá distribuovanou architekturu: Client-Server Bridge. Python engine funguje jako terminál, PHP servery jako centrální mozek pro validaci a MySQL jako perzistentní úložiště.

2. Databázový model

Využíváme relační model se dvěma provázanými tabulkami. Hesla jsou šifrována pomocí BCRYPT, což je standard pro moderní webové aplikace.

CREATE TABLE s18_users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE,
    password VARCHAR(255)
);

3. Síťové rozhraní (API)

Komunikace probíhá asynchronně přes REST-like endpointy. Hra odesílá data po uzavření herní relace.

# Python Request Example:
requests.post('save_score.php', data={'username': user, 'score': val})

4. Implementace bezpečnosti

Veškerý vstup do databáze je ošetřen pomocí PDO Prepared Statements, což eliminuje riziko SQL Injection útoků.
