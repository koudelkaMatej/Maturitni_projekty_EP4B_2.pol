Vývojářská příručka

Referenční manuál pro budoucí rozvoj projektu Space Invaders. Obsahuje konkrétní implementační postupy pro přidávání herních mechanik a modifikaci stávajících entit.

1. Vývojové prostředí

Projekt je vyvíjen v jazyce Python 3.10+. Pro izolaci závislostí využíváme virtuální prostředí (venv).

# Spuštění vývojového prostředí:
start_hry.bat

2. Implementační příklady

Pro přidání zvukové stopy k herní události:

# V metodě load_assets():
self.sound_shoot = pygame.mixer.Sound("data/shoot.wav")

# V místě spuštění:
self.sound_shoot.play()

3. Webová integrace

Zobrazení výsledků na webu je realizováno v index.php. SQL dotazy využívají JOIN nad tabulkami.

SELECT u.username, s.score FROM s18_scoreboard s
JOIN s18_users u ON s.user_id = u.id
ORDER BY s.score DESC

4. Testování

Unit testy lze spustit příkazem python main.py --test.
